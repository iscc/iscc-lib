## Step: Mint `gen_iscc_id_v1` on the Node.js (napi) binding

## Goal

Continue the #43 ISCC-IDv1 fan-out by exposing the experimental `gen_iscc_id_v1` minting function on
`crates/iscc-napi`, bringing the Node.js surface from 32 to 33 Tier 1 symbols. A v0.6.0 release
blocker for one of the 6 remaining minting surfaces.

## Alternatives Considered

- **Chosen:** napi `gen_iscc_id_v1` — smallest fully-local-verifiable slice; napi's `iscc_decode`
    already returns `version` as a bare `u8`, so decode of a V1 code round-trips today with **no
    version-enum widening needed** (unlike Python's `VS`). Pure single-crate change.
- **Rejected:** the C FFI surface — larger (needs `iscc.h` regen + freshness gate) and better done
    as a coherent C-family sequence with dotnet/cpp that wrap it. Sequencing does not reduce the
    total remaining steps, so pick the cleanest one now.

## Implementation Notes

- Signature (mirror the bare-string convention of `gen_meta_code_v0` at lib.rs:97, NOT the object
    form):
    `#[napi(js_name = "gen_iscc_id_v1")] pub fn gen_iscc_id_v1(timestamp: f64, hub_id: u16,   realm: u8) -> napi::Result<String>`
    → call
    `iscc_lib::gen_iscc_id_v1(timestamp as u64, hub_id,   realm).map(|r| r.iscc).map_err(|e| napi::Error::from_reason(e.to_string()))`.
- Use `f64` (JS `number`), not `u64`: valid timestamps are `< 2^52`, exactly representable in f64,
    and `number` is idiomatic where napi would otherwise force a `BigInt`. `hub_id`/`realm` are
    `number`.
- Golden vector: `gen_iscc_id_v1(1751831876325218, 1, 0) === "ISCC:MAIGHFECJMOPMIAB"`.
- Validation-error cases (core rejects, so `throws`): `hub_id = 4096` (≥2^12), `realm = 2` (∉{0,1}),
    `timestamp = 2**52`. Core validation order is ts ≥ 2^52 → hub ≥ 2^12 → realm.
- Round-trip: `iscc_decode(gen_iscc_id_v1(1751831876325218, 1, 0))` yields `maintype === 6` (Id),
    `version === 1`, `subtype === 0`.
- Follow the existing test style in `__tests__/functions.test.mjs` (`node:test` + `node:assert`,
    `describe`/`it`). Build the debug addon before testing: `npm run build:debug`.
